# ✅ Todo App — Vanilla JS
 
> AI 도구와 함께 직접 만들어보는 순수 자바스크립트 투두 앱
 
---
 
## 🚀 실행 방법
 
```bash
# 1. 저장소 클론
git clone 저장소 주소
cd todo-vanilla
 
# 2. VS Code에서 index.html 열기
# 3. Live Server 실행 (index.html 우클릭 → Open with Live Server)
```
 
---
 
## 📁 프로젝트 구조
 
```
todo-vanilla/
├── index.html   # 화면 레이아웃
├── style.css    # 스타일
└── app.js       # 기능 구현
```

## ✅ 구현 기능
 
### 기본 미션
| 기능 | 설명 |
|------|------|
| 📝 Todo CRUD | 생성 / 수정 / 완료 처리 / 삭제 |
| 🔍 상태별 필터링 | 전체 / 진행 중 / 완료 |

|------|------|

## 🤖 AI 활용 안내
 
본 과제는 **Claude**, **Gemini** 등 AI 도구를 활용해 코드를 생성하고,  
직접 수정·디버깅하며 완성했습니다.
 
AI를 어떻게 활용했는지:
- 초기 boilerplate 코드 생성
- 기능별 로직 구현 방향 질의
- 버그 원인 파악 및 리팩토링 제안
> AI가 작성한 코드를 그대로 쓰는 것이 아니라,  
> **이해하고 수정하며 내 코드로 만드는 과정**에 집중했습니다.
